# 集成桌面教学系统

面向高中教学场景的本地课件资源管理、课堂互动与教学工具集成软件。覆盖九大学科、三个年级的完整教材目录，把散落在电脑中的 PPT、Word、PDF、视频、图片等课件，按「学科 → 教材 → 章节 → 课程分类」统一归档。

所有课件原件保留在本机原路径，软件只保存索引、分类和备注，不上传云端。

GitHub 仓库：<https://github.com/BA4IIT/zzbz-courseware>


## 功能概览

- **九大学科**：语文、数学、英语（外研版）、物理、化学、生物、政治、历史、地理。
- **三年教材体系**：50 本必修/选择性必修教材 + 9 个高三复习专题，共 59 个教材/专题、355 个章节。
- **8 类课程分类**：新授课、复习课、习题课、实验课、微课、公开课、试卷讲评、备考专题。
- **本地文件管理**：
  - 多文件选择、文件夹递归扫描、文件/文件夹拖拽导入；
  - 根据文件夹层级和文件名自动识别学科、教材、章节、课程分类；
  - 单份、多份文件批量录入，支持直接粘贴本机文件路径；
  - 单个「另存为」、批量另存按分类自动建目录；
  - 批量下载：将多份课件打包成一个 ZIP 文件保存到本机；
  - 批量删除：按当前筛选结果多选移除索引，不删除课件原件。
- **英语 3500 词汇**：离线查询英文单词、音标和中文释义，支持中文/英文模糊搜索与 A—Z 首字母筛选；由 `wordlib（main）.csv` 整理出 3384 个词条。
- **学科提问**：课代表自行发布待讲题目并填写票数，同学可投票 +1，支持按票数排序、按学科筛选、标记已讲解。
- **AI 解答**：接入 DeepSeek API，支持上传 PDF/Word/Excel/TXT 文件、选择 DeepSeek Chat / Reasoner 与推理等级，并可进行 AI 翻译和 AI 图片转文字。
- **通用设置**：统一设置所有 AI 功能使用的 DeepSeek API Key、默认模型、推理等级、时事政治弹幕、各功能显隐和桌面悬浮快捷键。
- **桌面悬浮快捷键**：电脑右下角圆环快捷球，中间为校徽，可设置 1—8 个功能并调整悬浮球大小（240—380 px，默认白板/展台/批注）；可在通用设置中更换或关闭，关闭软件时快捷球自动退出。
- **屏幕批注**：截取当前屏幕作为背景，用画笔圈画批注并保存 PNG。
- **英语往年题**：按外研版课本、章节和题型，调用 DeepSeek 整理题目，标注题目类型和来源说明。
- **英语网**：内置浏览器打开 `https://cybertamin.xin/lang/en/`，支持后退、前进、刷新、回首页和系统浏览器打开。
- **环境音量**：用麦克风实时显示相对分贝，分自习课/晨读课两个场景提示。
- **触屏手势**：白板/展台在鼠标模式下支持双指外扩放大、内收缩小；内置浏览器支持左右滑动返回/前进。
- **单词天天练**：从高中英语 3500 词库随机抽题，英译汉/汉译英四选一，支持选择单词量、昵称和通关排名。
- **函数图像与科学计算器**：内置数学键盘输入表达式，绘制多条函数曲线，支持缩放/拖动；鼠标靠近曲线显示坐标和函数值；科学计算器支持三角函数、对数、幂和角度/弧度。
- **时事政治**：聚合人民网、新华网、中国新闻网、中国政府网等权威来源，并抓取新华网时政页面补足近期新闻，严格按电脑当前日期往前过滤（最长 6 个月），按高考命题相关性筛选并展示最多 50 条；调用 DeepSeek 匹配政治教材章节、概括命题角度，并支持滚动弹幕和原文跳转。
- **内置浏览器**：默认打开教学资源站，地址栏可自由访问其他页面并支持网页缩放；账号密码使用 Windows 系统加密保存在本机，登录页自动填充。
- **展台与白板**：自动获取摄像头，默认 4K 优先采集，支持自动/手动对焦、清晰度增强、画面旋转/镜像、全屏投放、画面锁定、拍照和全屏重连；展台缩放最高 500%，全屏展台/白板均可调笔粗。白板支持多页翻页、缩放、触屏双指缩放、多色批画和橡皮，可保存为 PNG；画笔按 3 倍超采样绘制，放大后保持清晰，并修复画笔状态双指误连线及缩小后四周无法书写的问题。
- **科目投票**：每天按日期为喜欢的学科投票，包含音乐、体育、微机、美术等 13 个学科，结果默认隐藏，需管理员密码查看。
- **手机投屏**：手机扫描二维码后通过同一 Wi‑Fi 投射摄像头或手机屏幕；蓝牙用于设备配对，不传输视频画面。
- **随机点名**：支持 Excel / CSV 学生名单导入、一次抽取多人、按权重随机抽取；后台可改名、调整权重、批量/指定删除。
- **白板翻页**：白板支持多页新增、上一页/下一页和删除当前页。
- **课程表**：可自由编辑节次、时间和课程，周六/周日分别维护 A 表、B 表。
- **课堂计时器**：支持 1—15 分钟预设、自定义分秒、暂停/重置、全屏显示和结束提示音。
- **U 盘检测**：检测可移动磁盘中的可疑可执行文件、伪装文档和 autorun 项，并可调用 Windows Defender 扫描。
- **检查更新**：从 GitHub Release 获取最新版本，优先使用加速通道并校验文件大小和 SHA-256；兼容 GitHub 匿名 API 限流。
- **检索与整理**：按年级、学科、教材、章节、课程分类组合筛选；支持全文搜索、收藏、最近使用、标签和教学备注。
- **课件预览**：PDF、图片、视频、音频内嵌预览；Office 文件调用本机 Office/WPS 打开。
- **数据安全**：文件仅引用本地路径，不复制、不修改、不删除原文件；完全离线运行。










## 下载安装

最新安装包与使用说明见 **[Releases](https://github.com/BA4IIT/zzbz-courseware/releases/latest)**：

- 安装包：`zzbz-courseware-2.2.0-setup.exe`
- 使用说明：`usage.txt`

安装包约 130 MB，因超过 GitHub 单文件 100 MB 限制，作为 Release 附件发布，不进入 Git 历史。安装程序支持自选安装目录，并在安装完成后创建桌面和开始菜单快捷方式。

### 运行环境

- Windows 10 / Windows 11（64 位）
- 打开 PPT / Word / PDF / 视频时，需要本机安装 Office、WPS、PDF 阅读器或对应播放器

## 开发

```powershell
npm install
npm start
npm run dist
```

- `npm run dist`：生成 Windows NSIS 安装包；
- `npm run dist:portable`：可选，生成绿色便携版；
- 构建产物输出到 `release/`，该目录不会提交到 Git。

### 目录结构

```text
.
├─ main.js                 Electron 主进程：文件扫描、本地 IPC、窗口、预览协议
├─ preload.js              安全的渲染进程 API 桥
├─ src/
│  ├─ index.html           界面结构
│  ├─ styles.css           浅蓝色视觉样式
│  ├─ catalog.js           九大学科/教材/章节数据
│  ├─ words.js             高中英语 3500 词汇离线数据
│  ├─ icons.js             内联 SVG 图标
│  ├─ detect.js            文件名与文件夹自动分类
│  ├─ app.js               界面逻辑
│  └─ mock.js              浏览器预览模式（?mock=1）
├─ assets/                 校徽、应用图标等静态资源
├─ scripts/                打包、图标、自动化验收脚本
├─ screenshots/            README 截图
└─ package.json            构建配置
```

## 本地数据

- 课件索引、学科提问、课程表、每日科目投票和学生名单保存在程序目录的 `data/courseware-library.json`；如果安装目录不可写，会自动使用 Windows 用户数据目录。
- `data/.runtime` 为运行缓存，不需提交到 Git。
- 建议定期在「数据管理」中导出 JSON 备份，同时保留课件原文件夹。
