# 高中课件管理系统

面向高中教学场景的本地课件资源管理工具。覆盖九大学科、三个年级的完整教材目录，把散落在电脑中的 PPT、Word、PDF、视频、图片等课件，按「学科 → 教材 → 章节 → 课程分类」统一归档。

所有课件原件保留在本机原路径，软件只保存索引、分类和备注，不上传云端。

GitHub 仓库：<https://github.com/BA4IIT/zzbz-courseware>


## 功能概览

- **九大学科**：语文、数学、英语、物理、化学、生物、政治、历史、地理。
- **三年教材体系**：50 本必修/选择性必修教材 + 9 个高三复习专题，共 59 个教材/专题、349 个章节。
- **8 类课程分类**：新授课、复习课、习题课、实验课、微课、公开课、试卷讲评、备考专题。
- **本地文件管理**：
  - 多文件选择、文件夹递归扫描、文件/文件夹拖拽导入；
  - 根据文件夹层级和文件名自动识别学科、教材、章节、课程分类；
  - 单份、多份文件批量录入，支持直接粘贴本机文件路径；
  - 单个「另存为」、批量另存按分类自动建目录；
  - 批量下载：将多份课件打包成一个 ZIP 文件保存到本机；
  - 批量删除：按当前筛选结果多选移除索引，不删除课件原件。
- **英语 3500 词汇**：离线查询英文单词、音标和中文释义，支持中文/英文模糊搜索与 A—Z 首字母筛选；由 `wordlib（main）.csv` 整理出 3384 个词条。
- **学科提问**：课代表自行发布待讲题目并填写票数，同学可投票 +1，支持按票数排序、按学科筛选、标记已讲解。
- **内置浏览器**：固定打开教学资源站，账号密码使用 Windows 系统加密保存在本机，登录页自动填充。
- **展台与白板**：自动获取摄像头并支持全屏投放、多种颜色批画和橡皮；独立白板可保存为 PNG。
- **课程表**：可自由编辑节次、时间和课程，周六/周日分别维护 A 表、B 表。
- **U 盘检测**：检测可移动磁盘中的可疑可执行文件、伪装文档和 autorun 项，并可调用 Windows Defender 扫描。
- **检查更新**：从 GitHub Release 获取最新版本，提示下载并打开新安装包。
- **检索与整理**：按年级、学科、教材、章节、课程分类组合筛选；支持全文搜索、收藏、最近使用、标签和教学备注。
- **课件预览**：PDF、图片、视频、音频内嵌预览；Office 文件调用本机 Office/WPS 打开。
- **数据安全**：文件仅引用本地路径，不复制、不修改、不删除原文件；完全离线运行。










## 下载安装

最新安装包与使用说明见 **[Releases](https://github.com/BA4IIT/zzbz-courseware/releases/latest)**：

- 安装包：`zzbz-courseware-1.4.0-setup.exe`
- 使用说明：`usage.txt`

安装包约 119 MB，因超过 GitHub 单文件 100 MB 限制，作为 Release 附件发布，不进入 Git 历史。安装程序支持自选安装目录，并在安装完成后创建桌面和开始菜单快捷方式。

### 运行环境

- Windows 10 / Windows 11（64 位）
- 打开 PPT / Word / PDF / 视频时，需要本机安装 Office、WPS、PDF 阅读器或对应播放器

## 开发

```powershell
npm install
npm start
npm run dist
```

- `npm run dist`：生成 Windows NSIS 安装包；
- `npm run dist:portable`：可选，生成绿色便携版；
- 构建产物输出到 `release/`，该目录不会提交到 Git。

### 目录结构

```text
.
├─ main.js                 Electron 主进程：文件扫描、本地 IPC、窗口、预览协议
├─ preload.js              安全的渲染进程 API 桥
├─ src/
│  ├─ index.html           界面结构
│  ├─ styles.css           浅蓝色视觉样式
│  ├─ catalog.js           九大学科/教材/章节数据
│  ├─ words.js             高中英语 3500 词汇离线数据
│  ├─ icons.js             内联 SVG 图标
│  ├─ detect.js            文件名与文件夹自动分类
│  ├─ app.js               界面逻辑
│  └─ mock.js              浏览器预览模式（?mock=1）
├─ assets/                 校徽、应用图标等静态资源
├─ scripts/                打包、图标、自动化验收脚本
├─ screenshots/            README 截图
└─ package.json            构建配置
```

## 本地数据

- 课件索引和学科提问保存在程序目录的 `data/courseware-library.json`；如果安装目录不可写，会自动使用 Windows 用户数据目录。
- `data/.runtime` 为运行缓存，不需提交到 Git。
- 建议定期在「数据管理」中导出 JSON 备份，同时保留课件原文件夹。
