枣庄八中 · 高中课件管理系统
Windows 安装版 v1.3.0 · 使用说明
========================================

【安装】
1. 双击「枣庄八中高中课件管理系统-1.3.0-安装包.exe」。
2. 在安装向导中选择安装位置：
   · 可使用默认位置；
   · 也可点击「浏览」，自行选择任意有写入权限的目录。
3. 安装程序会自动在桌面创建「枣庄八中高中课件管理系统」快捷方式，
   并在开始菜单创建程序入口。
4. 安装完成后直接运行即可。

如果安装中提示「不能打开要写入的文件」：
· 点「中止」，关闭旧版软件和安装程序；
· 删除或改名旧的安装目录，或直接选择新的安装位置；
· 必要时右键安装包 →「以管理员身份运行」；
· 不要把安装目录设在受保护的系统目录中。

【首次启动】
首次启动会自动创建 data 数据文件夹，并显示 21 条示例课件，
帮助熟悉界面。导入真实课件后，可在首页提示条或
「数据管理 → 清除示例数据」中一键清除示例。

【软件特点】
· 九大学科：语文、数学、英语、物理、化学、生物、政治、历史、地理。
· 三个年级：高一、高二、高三，含必修、选择性必修及高三复习专题。
· 59 个教材/复习专题、349 个章节/专题，完整覆盖高中三年教材分类。
· 8 种课程分类：新授课、复习课、习题课、实验课、微课、公开课、
  试卷讲评、备考专题。
· 文件只记录本机路径，不复制、不移动、不上传；原件保留在原文件夹。
· 支持拖拽导入、文件夹递归扫描、自动识别学科/教材/章节/分类。
· 支持搜索、年级/教材/章节/课程分类筛选、收藏、最近使用、标签、备注。
· 支持 PDF、图片、视频、音频内嵌预览；PPT/Word 可调用本机 Office/WPS 打开。
· 支持导出 CSV 课件清单、导出/恢复 JSON 数据备份。
· 批量录入：一次选择多个文件、扫描文件夹，或粘贴本机文件路径。
· 单个课件可「另存为」；多份课件可「批量另存」到目标文件夹，
  自动按学科/教材/章节分类，并生成课件清单.csv。
· 批量下载：多份课件可打包为一个 ZIP 文件，压缩包内同样
  按学科/教材/章节整理，并附带课件清单.csv。
· 批量删除：按当前筛选结果多选移除课件索引，不删除电脑中的原文件。
· 英语 3500 词汇：左侧「学习工具 → 英语 3500」，离线查询
  单词、音标和中文释义，支持中文/英文搜索和 A—Z 首字母筛选。
· 学科提问：左侧「学习工具 → 学科提问」，课代表自行发布题目
  并填写票数，同学可投票 +1；老师可按票数优先讲题。
· 界面右下角显示「该软件已在 GitHub 开源」标识。

【数据安全】
· 软件完全离线，不上传任何文件或使用数据。
· 课件原件不会被软件修改或删除。
· 课件索引和学科提问保存在 data\courseware-library.json
  （具体位置可通过「数据管理 → 打开数据文件夹」查看）。
· 「导出数据备份」会同时导出课件索引和学科提问。
· data 文件夹中的 .runtime 是软件运行缓存，不需要手动备份。
· 移动课件文件后，系统会标记「文件缺失」，重新导入即可。
· 建议把 data\courseware-library.json 与课件原文件夹定期备份。

【常用操作】
· 导入文件：点击右上角「导入课件」→ 选择文件。
· 批量导入：点击右上角「导入课件」→ 扫描文件夹，
  或直接把文件夹拖入窗口。
· 自动分类：软件会根据文件夹层级和文件名识别；
  导入前可批量或逐条校正。
· 修改分类：点击课件卡片 → 右侧详情面板 →
  修改学科/教材/章节/分类 → 保存。
· 批量录入：课件库标题右侧「批量录入」→ 选择多个文件/
  扫描文件夹/粘贴本机路径 → 核对分类 → 批量录入。
· 单个另存：详情面板 → 「另存为」。
· 批量另存：课件库标题右侧「批量另存」→ 勾选课件 →
  选择目标文件夹，自动分类复制并生成清单。
· 批量下载：课件库标题右侧「批量下载」→ 勾选课件 →
  选择 ZIP 保存位置，打包下载。
· 批量删除：课件库标题右侧「批量删除」→ 勾选记录 →
  「删除选中」；只删除索引，不会删除原文件。
· 英语词汇：左侧「学习工具 → 英语 3500」→ 输入单词或中文 →
  查看音标和释义；可按 A—Z 浏览。
· 学科提问：左侧「学习工具 → 学科提问」→ 选择学科、
  填写题目/题号、问题说明和当前票数 → 发布问题。
  同学点「投票 +1」，课代表可点「改票数」手动录入；
  老师讲完后点「标记已讲解」。
· 打开原件：详情面板 → 打开原文件；或在文件夹中显示。
· 搜索：右上角搜索框，快捷键 Ctrl+K。
· 关闭面板：Esc。
· 清除示例：首页提示条「清除示例」，或
  「数据管理 → 清除示例数据」。

【首次运行提示】
软件未购买商业代码签名证书。若 Windows SmartScreen 提示
「Windows 已保护你的电脑」，请点击「更多信息」→「仍要运行」。

【系统要求】
· Windows 10 / Windows 11（64 位）
· 打开 PPT/Word/PDF/视频时，需要本机安装 Office、WPS、
  PDF 阅读器或播放器。

【卸载】
1. 建议先在「数据管理」中导出数据备份。
2. 退出软件。
3. 在 Windows「设置 → 应用 → 已安装的应用」中卸载，
   或运行安装目录中的卸载程序。
4. 电脑中的课件原文件不受任何影响。

【常见问题】
Q：为什么提示文件缺失？
A：课件原文件被移动、重命名或删除了。把文件放回原路径，
   或重新导入。

Q：导入会复制课件吗？
A：不会。软件只记录路径，不占用额外磁盘空间。

Q：安装时可以自选安装位置吗？
A：可以。安装向导会显示安装位置页面，点击「浏览」即可选择。

Q：怎么打开使用说明？
A：点击界面右下角状态栏中的「使用说明」，或点击右上角问号按钮。

Q：换电脑怎么迁移？
A：复制课件原文件夹并保持路径一致，同时备份
   data\courseware-library.json；路径不一致时重新导入相应文件夹。

Q：为什么要先安装 Office/WPS？
A：软件本身不内嵌 PPT/Word 编辑器，打开 Office 文件时
   会调用系统默认程序。
