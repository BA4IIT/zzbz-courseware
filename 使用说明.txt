枣庄八中集成桌面教学系统
Windows 安装版 v2.3.2 · 使用说明
========================================

【安装】
1. 双击「枣庄八中集成桌面教学系统-2.3.2-安装包.exe」。
2. 在安装向导中选择安装位置：
   · 可使用默认位置；
   · 也可点击「浏览」，自行选择任意有写入权限的目录。
3. 安装程序会自动在桌面创建「枣庄八中集成桌面教学系统」快捷方式，
   并在开始菜单创建程序入口。
4. 安装完成后直接运行即可。

如果安装中提示「不能打开要写入的文件」：
· 点「中止」，关闭旧版软件和安装程序；
· 删除或改名旧的安装目录，或直接选择新的安装位置；
· 必要时右键安装包 →「以管理员身份运行」；
· 不要把安装目录设在受保护的系统目录中。

【首次启动】
首次启动会自动创建 data 数据文件夹，并显示 21 条示例课件，
帮助熟悉界面。导入真实课件后，可在首页提示条或
「数据管理 → 清除示例数据」中一键清除示例。

【软件特点】
· 九大学科：语文、数学、英语、物理、化学、生物、政治、历史、地理。
· 三个年级：高一、高二、高三，含必修、选择性必修及高三复习专题。
· 59 个教材/复习专题、355 个章节/专题，完整覆盖高中三年教材分类。
· 8 种课程分类：新授课、复习课、习题课、实验课、微课、公开课、
  试卷讲评、备考专题。
· 文件只记录本机路径，不复制、不移动、不上传；原件保留在原文件夹。
· 支持拖拽导入、文件夹递归扫描、自动识别学科/教材/章节/分类。
· 支持搜索、年级/教材/章节/课程分类筛选、收藏、最近使用、标签、备注。
· 支持 PDF、图片、视频、音频内嵌预览；PPT/Word 可调用本机 Office/WPS 打开。
· 支持导出 CSV 课件清单、导出/恢复 JSON 数据备份。
· 批量录入：一次选择多个文件、扫描文件夹，或粘贴本机文件路径。
· 单个课件可「另存为」；多份课件可「批量另存」到目标文件夹，
  自动按学科/教材/章节分类，并生成课件清单.csv。
· 批量下载：多份课件可打包为一个 ZIP 文件，压缩包内同样
  按学科/教材/章节整理，并附带课件清单.csv。
· 批量删除：按当前筛选结果多选移除课件索引，不删除电脑中的原文件。
· 英语 3500 词汇：左侧「学习工具 → 英语 3500」，离线查询
  单词、音标和中文释义，支持中文/英文搜索和 A—Z 首字母筛选。
· 学科提问：左侧「学习工具 → 学科提问」，课代表自行发布题目
  并填写票数，同学可投票 +1；老师可按票数优先讲题。
· AI 解答：左侧「学习工具 → AI 解答」，填写 DeepSeek API Key，
  支持上传 PDF/Word/Excel/TXT、选择模型和推理等级、AI 翻译、
  图片转文字；Key 使用 Windows 加密保存在本机。
· 通用设置：统一设置所有 AI 功能的 API Key、默认模型/推理等级，
  以及时事政治弹幕、各功能显隐和桌面悬浮快捷键。
· 桌面悬浮快捷键：电脑右下角圆环快捷球，中间为八中校徽，
  可设置 1—8 个功能（默认白板/展台/批注），可在 180—360 px
  之间整体缩放背景、按钮和文字；点击校徽折叠为仅校徽，再点恢复。
· 关闭主窗口后软件隐藏到系统托盘，悬浮球保持显示；
  托盘菜单可显示主界面或真正退出（退出时才关闭悬浮球）。
· 屏幕批注：透明置顶窗口直接盖在应用上层，颜色/笔粗/橡皮/清空/
  保存 PNG，Esc 退出。
· 北京时间：带 1—12 数字的钟表/数字样式，可全屏或悬浮置顶，
  悬浮大小在通用设置中调整（160—480 px）。
· 倒计时：数字/钟表样式可切换。
· 英语网：地址栏可输入其他网址并打开。
· 展台：右上角新增全屏投放；从悬浮球打开展台会自动进入全屏。
· 英语往年题：按外研版课本/章节/题型调用 DeepSeek 整理题目，
  标明题目类型，来源不确定时标注模拟题。
· 英语网：内置浏览器打开 https://cybertamin.xin/lang/en/，
  支持后退、前进、刷新、回首页和系统浏览器打开。
· 环境音量：麦克风实时显示相对分贝，分自习课/晨读课场景提示。
· 单词天天练：左侧「学习工具 → 单词天天练」，输入昵称、选择
  单词量，进行英译汉/汉译英四选一挑战，并按昵称记录通关排名。
· 函数图像：支持同款数学键盘输入表达式、绘制多条曲线、
  缩放、拖动、颜色切换，鼠标靠近曲线显示坐标和函数值。
· 科学计算器：支持三角函数、对数、幂、根号和角度/弧度。
· 时事政治：聚合人民网、新华网、中国新闻网、中国政府网等
  权威来源，并抓取新华网时政页面补足近期新闻；严格按电脑当前
  时间往前过滤（最长 6 个月），按高考命题相关性筛选并最多展示
  50 条；调用 DeepSeek 匹配政治教材章节、生成命题角度和滚动弹幕。
· 内置浏览器：默认打开 zz8zszy.cn，地址栏可访问其他网址、
  支持网页缩放；账号密码加密保存并自动填充。
· 展台：默认 4K 优先采集，支持 2K/1080P/720P/480P、自动/手动
  对焦、清晰度增强、旋转/镜像、全屏、50%—500% 缩放、鼠标移动、
  多色批画、橡皮、画面锁定、拍照和全屏重连；锁定后仍可转向/缩放；
  全屏时自动对焦/对焦近/对焦远/重连位于屏幕右侧。
· 白板：多色板书、橡皮、清空、缩放、鼠标移动、双指缩放、
  多页翻页、全屏控制栏，可保存为 PNG；画笔 3 倍超采样，放大清晰；
  缩小后四周仍可书写，画笔状态下双指不会连出直线。
· 内置浏览器：支持左右滑动返回/前进和横向滚轮手势。
· 科目投票：每天按日期投票选学科（含音乐、体育、微机、美术），
  结果需要管理员密码查看。
· 随机点名：支持 Excel/CSV 名单导入、一次抽取多人、按权重抽取；
  后台可改名、调整权重、批量/指定删除；抽取时尽量避开上一轮姓名。
  投票结果和随机点名后台密码可在通用设置中修改。
· 手机投屏：生成二维码，手机与电脑同一 Wi-Fi 扫码后投摄像头/屏幕；
  蓝牙入口用于配对，不传输视频。
· 课堂计时器：预设/自定义时间，支持暂停、重置、数字/钟表样式、
  全屏和提示音。

· U 盘检测：检查可疑可执行文件、伪装文档和 autorun 项，

【数据安全】
· 课件管理功能完全离线，不上传课件或使用数据。
· 使用 AI 解答时问题会发送到 DeepSeek；手机投屏只在同一局域网传输。
· 课件原件不会被软件修改或删除。
· 课件索引、学科提问、课程表、每日投票、学生名单和单词成绩保存在
  data\courseware-library.json（具体位置可通过
  「数据管理 → 打开数据文件夹」查看）。
· 「导出数据备份」会同时导出以上数据。
· data 文件夹中的 .runtime 是软件运行缓存，不需要手动备份。
· 移动课件文件后，系统会标记「文件缺失」，重新导入即可。
· 建议把 data\courseware-library.json 与课件原文件夹定期备份。

【常用操作】
· 导入文件：点击右上角「导入课件」→ 选择文件。
· 批量导入：点击右上角「导入课件」→ 扫描文件夹，
  或直接把文件夹拖入窗口。
· 自动分类：软件会根据文件夹层级和文件名识别；
  导入前可批量或逐条校正。
· 修改分类：点击课件卡片 → 右侧详情面板 →
  修改学科/教材/章节/分类 → 保存。
· 批量录入：课件库标题右侧「批量录入」→ 选择多个文件/
  扫描文件夹/粘贴本机路径 → 核对分类 → 批量录入。
· 单个另存：详情面板 → 「另存为」。
· 批量另存：课件库标题右侧「批量另存」→ 勾选课件 →
  选择目标文件夹，自动分类复制并生成清单。
· 批量下载：课件库标题右侧「批量下载」→ 勾选课件 →
  选择 ZIP 保存位置，打包下载。
· 批量删除：课件库标题右侧「批量删除」→ 勾选记录 →
  「删除选中」；只删除索引，不会删除原文件。
· 英语词汇：左侧「学习工具 → 英语 3500」→ 输入单词或中文 →
  查看音标和释义；可按 A—Z 浏览。
· 学科提问：左侧「学习工具 → 学科提问」→ 选择学科、
  填写题目/题号、问题说明和当前票数 → 发布问题。
  同学点「投票 +1」，课代表可点「改票数」手动录入；
  老师讲完后点「标记已讲解」。
· AI 解答：左侧「学习工具 → AI 解答」→ 填写并保存 API Key →
  选择模型/推理等级 → 输入问题或上传附件 → 发送给 AI；
  也可切换「AI 翻译」「图片转文字」。
· 通用设置：左侧「课堂工具 → 通用设置」→ 设置全局 API Key、
  模型、推理等级、时事政治弹幕、功能显隐和桌面快捷球。
· 桌面快捷球：默认右下角白板/展台/批注；设置里可配置 1—8 个
  功能和 240—380 px 外圈大小，或关闭；软件关闭时快捷球一起关闭。
  大小只影响外圈，图标文字和主界面不缩放。
· 屏幕批注：左侧「课堂工具 → 批注」或悬浮球「批注」→ 透明层直接批画 →
  保存 PNG → Esc/退出批注。
· 英语往年题：左侧「学习工具 → 英语往年题」→ 选择课本/章节/
  题型 → AI 查找题目。
· 英语网：左侧「学习工具 → 英语网」→ 直接打开 cybertamin.xin
  英语页面，可后退、前进、刷新或系统浏览器打开。
· 环境音量：左侧「课堂工具 → 环境音量」→ 选择自习/晨读 →
  开始检测并允许麦克风。
· 单词天天练：左侧「学习工具 → 单词天天练」→ 输入昵称 →
  选择单词量 → 开始答题；答完自动进入通关排名。
· 函数图像：左侧「学习工具 → 函数图像」→ 键盘输入或使用
  下方数学键盘 → 绘制；鼠标拖动平移，滚轮/按钮缩放。
· 科学计算器：左侧「学习工具 → 科学计算器」→ 点击按键 →
  = 计算；支持 RAD/DEG。
· 时事政治：左侧「学习工具 → 时事政治」→ 选择课本/章节/
  时间范围（最长 6 个月）→ AI 搜索并匹配 → 查看章节和命题角度
  → 点击前往新闻。页面最多显示 50 条，并显示本次查询起止时间。
· 内置浏览器：左侧「课堂工具 → 内置浏览器」→ 地址栏可输入
  任意网址、支持 50%—200% 缩放；在右侧保存账号密码，登录页自动填充。
· 展台：左侧「课堂工具 → 展台」→ 自动连接摄像头 →
  选择分辨率/清晰度/方向/对焦；可锁定画面、拍照；
  用右侧缩放、鼠标、颜色、橡皮操作；全屏后底部工具栏可直接控制。
· 白板：左侧「课堂工具 → 白板」→ 颜色/粗细/橡皮/缩放/
  鼠标移动；可新建/上一页/下一页/删除页面；全屏后底部工具栏
  也可翻页；可保存当前页图片。
· 科目投票：左侧「课堂工具 → 科目投票」→ 点击学科投票；
  查看结果需管理员密码。
· 随机点名：左侧「课堂工具 → 随机点名」→ 导入 Excel/CSV →
  随机抽取；后台设置需管理员密码，可调整选中权重。
· 手机投屏：左侧「课堂工具 → 手机投屏」→ 生成投屏码 →
  手机同一 Wi-Fi 扫码 → 选择摄像头或屏幕共享。
· 计时器：左侧「课堂工具 → 计时器」→ 选择预设或输入分秒 →

· U 盘检测：左侧「课堂工具 → U 盘检测」→ 刷新磁盘 →

· 检查更新：右上角刷新按钮，或数据管理→关于系统。
· 打开原件：详情面板 → 打开原文件；或在文件夹中显示。
· 搜索：右上角搜索框，快捷键 Ctrl+K。
· 关闭面板：Esc。
· 清除示例：首页提示条「清除示例」，或
  「数据管理 → 清除示例数据」。

4. 电脑中的课件原文件不受任何影响。

【常见问题】
Q：为什么提示文件缺失？
A：课件原文件被移动、重命名或删除了。把文件放回原路径，
   或重新导入。

Q：导入会复制课件吗？
A：不会。软件只记录路径，不占用额外磁盘空间。

Q：安装时可以自选安装位置吗？
A：可以。安装向导会显示安装位置页面，点击「浏览」即可选择。

Q：怎么打开使用说明？
A：点击界面右下角状态栏中的「使用说明」，或点击右上角问号按钮。

Q：换电脑怎么迁移？
A：复制课件原文件夹并保持路径一致，同时备份
   data\courseware-library.json；路径不一致时重新导入相应文件夹。

Q：为什么要先安装 Office/WPS？
A：软件本身不内嵌 PPT/Word 编辑器，打开 Office 文件时
   会调用系统默认程序。
